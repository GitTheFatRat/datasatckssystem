# DashStack - Modern Admin & Analytics Dashboard

A responsive, high-performance web dashboard application built with modern React and Vite. Designed with a dark theme aesthetic, comprehensive business analytics, and management workflows.

## Features

- **Executive Analytics & KPI Tracking**:
  - Dual dashboard modes: Real-time Sales Overview and in-depth Revenue & Customer Analytics.
  - Interactive visual charts powered by Recharts (spline wave curves, donut charts, area trends).
  - Recent deals table with status indicators and metric comparison summaries.

- **E-Commerce & Inventory Management**:
  - **Products**: Featured promotions banner carousel, product catalog, rating stars, and color chips.
  - **Favorites**: Bookmarked product collection with quick toggle actions and empty state illustration.
  - **Product Stock**: Detailed inventory ledger with image thumbnails, color swatches, and stock piece counters.
  - **Order Lists**: Multi-dimensional filtering system (date range selector, order type modal, status chips, and pagination).

- **Productivity & Communication**:
  - **Inbox**: Categorized email client with custom labels, message threads, and reply composer.
  - **Calendar**: Monthly schedule planner with event highlights, day-level view, and event creation modal.
  - **To-Do List**: Task management with priority stars and completion toggling.

- **Enterprise & Team Tools**:
  - **Contact Directory**: Card-based directory with instant messaging actions and new contact modal.
  - **Team Directory**: Team members list by department, status indicators (Active / On Leave), and member profiles.
  - **Invoice**: Formal client invoice view with itemized calculations, VAT, discounts, and print styling.
  - **Data Table**: Project tracking table with progress bars, status tags, and inline records management.
  - **UI Elements**: Component showcase featuring bar charts, pie charts, badges, and toggle switches.

- **System & Security**:
  - **Authentication**: Login, Account Registration, and Password Reset workflows.
  - **Account Settings**: Platform configuration, SEO metadata settings, and branding controls.
  - **Global Header**: Search bar, multi-language selector (English, French, Spanish), and notification center.

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Data Visualization**: Recharts
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design System with CSS Custom Properties (Theme Tokens)
- **Code Quality**: Oxlint

## Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GitTheFatRat/datasatckssystem.git
   cd datasatckssystem
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
